# Finvora

Financial education, NGX company research and investment simulation platform.

**Status:** Phase 1 prototype built. See [docs/PHASE1_STATUS.md](docs/PHASE1_STATUS.md) for what works, how to run and test it, the reviewer guide, undecided values and what remains. Background: [docs/TECHNICAL_PROPOSAL.md](docs/TECHNICAL_PROPOSAL.md) and [docs/PROTOTYPE_BUILD_PLAN.md](docs/PROTOTYPE_BUILD_PLAN.md).

```bash
npm install
npm test && npm run build      # static site in apps/web/out
```

> Educational use only. Finvora does not execute trades, manage assets or provide financial advice.
